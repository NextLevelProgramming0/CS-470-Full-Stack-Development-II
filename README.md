# Module 2 – Dockerizing a Full-Stack Application

## 📌 Overview

This module demonstrates how to containerize and run a full-stack web application using **Docker**.  
The application consists of:

- A **Node.js / LoopBack API**
- An **Angular frontend**
- A **MongoDB database**

Two Docker approaches are shown in this module:

1. **Manual Docker usage**
   - Building images
   - Running containers using `docker run`

2. **Docker Compose usage**
   - Building images
   - Running multiple containers together
   - Connecting the API to MongoDB automatically

This module demonstrates an understanding of Docker fundamentals, container networking, and multi-container orchestration.

---

## 🧰 Technologies Used

- Docker & Docker Compose
- Node.js
- Angular
- MongoDB
- LoopBack API framework
